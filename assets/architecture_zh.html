knowhow-miner 系统分层架构 (Layered Architecture)

面向复杂工业通信的认知逆向工程母机 • 工程师四阶决策状态机提取 (RULE-PAR-05) • 工业 Reasoning Agent 评测基准

1. 核心层：认知逆向工程与状态机

  • • 四阶决策状态机 (RULE-PAR-05)：提取 Trigger & Noise ➔ First-Principles Deduction ➔ Tactical Compromise ➔ State Lock。
  • • 双轨因果解耦：剥离 8D 管理公关免责辞令，直击物理第一性原理真因。
  • • 奥卡姆剃刀剪枝 (RULE-PAR-01)：剔除 4M 复合编造借口，锁定单点物理突变。
  • • 观测位移判定 (RULE-THM-02)：识别检测工位后移与相变脱溶剂收缩带来的假性劣化。

2. 应用层：确定性语义与 MCP 接口

  • • 标准 MCP Server 协议：原生 SSE 与 JSON-RPC 端点，秒级挂载至 Claude / Cursor / WorkBuddy。
  • • NVIDIA Auto-Ontology 语义层：3NF 关系表与行业术语同义词图谱映射，确定性 Text-to-SQL 零幻觉。
  • • 双重资产落地交付：流片前 DFM 规则公式（Enclosure 裕量）+ 产线调机 Offset 补偿账本。

3. 贯穿层：五级评测沙盒 (Eval Gym)

  • • Level 1 (清洗脱敏)：法务免责过滤 100%，工艺参数零误删 (0 FP)，正文抽取 100%。
  • • Level 3 (状态机与因果)：8D 解耦率 100%，四阶工程师决策状态机提取率 100%。
  • • Level 4-5 (可执行性与血统)：DFM 公式解析 100%，原始邮件 Message-ID 溯源 100%。
  • • Agent 推理沙盒：验证工业智能体能否基于真实杂乱现场推导出正确决策（基准得分 93.5/100）。
